# Image Annotation Portfolio — Everyday Objects

## Project Overview

A personal portfolio project demonstrating manual image annotation using Roboflow. The project focuses on drawing bounding boxes around everyday objects and assigning the appropriate class labels for object detection.

## Tools
- Roboflow Annotate
- GitHub

## Dataset
- 20 images
- Object detection using bounding boxes
- 9 object classes

## Object Classes
- `book`
- `bottle`
- `cup`
- `glasses`
- `laptop`
- `pencil`
- `phone`
- `spoon`
- `watch`

## Workflow
1. Collected images for annotation practice.
2. Uploaded images to Roboflow.
3. Drew bounding boxes around visible target objects.
4. Assigned class labels consistently.
5. Reviewed annotations for accuracy.

## Quality Check
- Checked bounding box placement.
- Checked class label consistency.
- Avoided guessing unclear or heavily occluded objects.
